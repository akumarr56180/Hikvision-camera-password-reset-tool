🔐 Hikvision Camera Password Reset Tool

A simple and efficient tool to reset passwords for Hikvision CCTV cameras, DVRs, and NVRs without requiring the current username or password.

🚀 Features

Reset password without old credentials
Automatic network scanning for devices
Detect and display camera IP addresses
Fast and easy-to-use interface
Supports multiple Hikvision devices
No data loss during reset

📌 How It Works

Connect your computer to the same network as the camera
Launch the tool
Scan the network for connected devices
Copy the detected camera IP address
Paste the IP into the tool
Click reset — access restored instantly

⚙️ Requirements

Windows OS (recommended)
Local network access
Hikvision device is connected to the same network

📥 Installation

git clone https://github.com/akumarr56180/hikvision-password-reset-tool.git
cd hikvision-password-reset-tool

Run the executable file or script based on your setup.
